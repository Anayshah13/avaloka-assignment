# Avaloka assignment

LRU cache and event scheduler for the Avaloka AI intern assignment.

- `lru_cache.py`: LRU cache (dict + doubly linked list) and a thread-safe version
- `event_scheduler.py`: can attend all, min rooms, room assignment
- `tests.py`: run `python tests.py`

Full writeup is in `Anay_Shah_Avaloka_Assignment.pdf`.
